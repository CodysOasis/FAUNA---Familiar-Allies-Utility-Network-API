# FAUNA — Familiar Allies Utility Network API

A SMAPI framework that adds Familiars as a new entity class to Stardew Valley.  
Familiars are living companions with daily needs, a trust system, and unlockable abilities.

FAUNA provides the engine. You'll need a compatible content pack to add any creatures.

---

## For Players

- Download FAUNA and drop it in your `Stardew Valley/Mods/` folder
- Install a compatible content pack (see below)
- Build a **Familiar Den** through Robin's shop to house your familiars
- Craft an **Ouija Board** to summon and purchase familiars

**Compatible content packs:**
- [[TotAG] Vael's Familiars](https://www.nexusmods.com/stardewvalley/mods/45156) — 11 familiars from Vael's pack in the Aether Glade

---

## For Mod Authors

FAUNA content packs are standard **Content Patcher** packs — no C# needed, just JSON and sprite assets.

Full documentation: [`docs/author-guide.md`](docs/author-guide.md)  
Example pack: [`examplepack/[FAUNA]VaelsFamiliars`](examplepack/%5BFAUNA%5DVaelsFamiliars)
